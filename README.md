# Ayush Ghosh — Portfolio starter

A beginner-friendly, responsive developer portfolio built with plain HTML, CSS, and JavaScript. It is designed to be easy to edit and deploy on GitHub Pages.

## Preview it on your computer

1. Download and unzip this project.
2. Open the `ayush-portfolio` folder.
3. Double-click `index.html` to open the site in a browser.
4. To edit the code, open the folder in a code editor such as Visual Studio Code.

The Google Fonts in the design load when you are connected to the internet. The site itself does not need a build step.

## Personalize it before publishing

Open `index.html` and search for these items:

- `YOUR-EMAIL@example.com` — replace with an email address you want visitors to use. Until changed, the email button is only a placeholder.
- `https://www.linkedin.com/` — replace with your LinkedIn profile, or remove that link if you do not want to share it.
- `ayushghosh20088002-web` — check that the GitHub profile and NovaCalc source links point to your accounts and repository.
- Update the short introduction, learning status, and service descriptions as your skills grow.

The current portfolio links to your live NovaCalc project: https://ayushghosh20088002-web.github.io/novacalc/ . JavaScript is described as beginner/exploring because NovaCalc is an existing project; adjust that wording if it does not match your experience.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `ayushghosh20088002-web.github.io` (use your own GitHub username in place of `ayushghosh20088002-web`).
2. Upload the contents of this folder to the repository's top level. Make sure `index.html`, `style.css`, and `script.js` are at the repository root, not inside an extra nested folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait a few minutes. GitHub will show the published website link on the Pages settings screen. It will normally be `https://YOUR-USERNAME.github.io/`.

If you already created a repository for the portfolio, you can use that instead. For a repository named `portfolio`, the default Pages address is usually `https://YOUR-USERNAME.github.io/portfolio/`; choose `main` and `/ (root)` in Pages settings.
